# Youtube Manage

YouTube Auto Content Generator — Generate AI-powered videos and upload them automatically to YouTube.

## Features

- 🎬 Generate video from keyword/topic using AI
- 📅 Schedule automatic uploads
- 📂 Video library management
- 📤 Direct upload to YouTube
- ⚙️ Configurable API settings
- 🌙 Dark/Light mode

## Tech Stack

- **Frontend:** Next.js + Tailwind CSS
- **Backend:** Python (FastAPI)
- **CLI:** Python (Typer)
- **Database:** SQLite
- **Video Processing:** FFmpeg
- **AI:** Gemini API, ElevenLabs, Leonardo AI, Edge TTS

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
